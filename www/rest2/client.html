📖 API 文件

GET /api/users
描述：取得所有使用者列表（支援分頁和篩選）
查詢參數：
  • status: 篩選狀態 (active, inactive, deleted)
  • page: 分頁號碼 (預設: 1)
  • limit: 每頁數量 (預設: 10)
GET /api/users/{id}
描述：根據ID取得單一使用者資訊
參數： id - 使用者ID
POST /api/users
描述：建立新使用者
必需欄位： name, email
選用欄位： phone, bio, age, city, country
PUT /api/users/{id}
描述：更新使用者資訊
參數： id - 使用者ID
可更新欄位： name, email, phone, bio, age, city, country, status
DELETE /api/users/{id}
描述：刪除使用者
參數： id - 使用者ID
查詢參數： hard=true (進行硬刪除，預設為軟刪除)
GET /api/search
描述：搜尋使用者
查詢參數：
  • q: 搜尋關鍵字 (必需)
  • field: 指定搜尋欄位 (name, email, phone, city, country)
